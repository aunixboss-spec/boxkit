boxkit

Набор CLI-утилит для терминала на чистом Python. Ничего устанавливать не нужно: скачал и запустил.

Начать за 10 секунд ⭐ Звезду в репо 
$ python boxkit/genpass.py --length 24
Rm#8vTq2wLpZx94Kd7JfNc3b
$ python boxkit/organizer.py ~/Downloads
photo.jpg   -> images/photo.jpg
report.pdf  -> documents/report.pdf
song.mp3    -> audio/song.mp3
▊

Утилиты

organizer

Раскладывает файлы по папкам-категориям: изображения, документы, аудио, видео и архивы.

python boxkit/organizer.py ~/Downloads

genpass

Криптостойкие пароли через модуль secrets. Настраиваемая длина, без неоднозначных символов.

python boxkit/genpass.py -l 24 -c 3

diskreport

Показывает, какие файлы съедают место. Топ самых больших файлов в дереве каталогов.

python boxkit/diskreport.py . --top 10

renamer

Массовое переименование с нумерацией. Идеально для фото с отпуска или скриншотов.

python boxkit/renamer.py ./DCIM --prefix trip

timer

Помодоро и обратный отсчёт прямо в терминале. Без браузера, без уведомлений, без шума.

python boxkit/timer.py 25 --label "Работа"

roadmap

Поиск дубликатов по хэшу, генератор QR-кодов, цветной ANSI-вывод. Предлагай идеи в issues!

Быстрый старт

1

Склонируй репо

git clone https://github.com/aunixboss-spec/boxkit.git
cd boxkit
2

Запусти любую утилиту

python boxkit/organizer.py --help
3

Всё 🎉

Никаких pip install, виртуальных окружений и конфигов. Нужен только Python 3.8+.
