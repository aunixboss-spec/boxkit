# Как внести вклад

Спасибо за интерес к boxkit! Проект специально простой: чистый Python, ноль зависимостей.

## Правила

1. **Только стандартная библиотека.** Никаких `pip install`.
2. **Безопасно по умолчанию.** Всё, что удаляет/перемещает/переименовывает, сначала показывает план (`--dry-run`) или спрашивает подтверждение.
3. **Один формат.** У утилиты есть докстринг с примерами и понимаемый `--help`.
4. **Тесты обязательны.** Новая утилита или фикc — без тестов не принимаются.

## Локальный запуск

```bash
git clone https://github.com/aunixboss-spec/boxkit.git
cd boxkit
python -m unittest discover tests
```

## Стиль

- Python 3.8+, без внешних зависимостей
- Комментарии и сообщения CLI — на русском, код и имена — на английском
- Одна утилита = один файл в `boxkit/`, тесты — в `tests/test_<имя>.py`

## Пул-реквест

1. Сделайте форк и ветку: `git checkout -b my-feature`
2. Убедитесь, что тесты зелёные: `python -m unittest discover tests`
3. Описывайте изменения в сообщении коммита: `feat:` / `fix:` / `docs:` / `test:` / `ci:`

Нашли баг? Откройте [issue](https://github.com/aunixboss-spec/boxkit/issues) с примером команды и выводом.
